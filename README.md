# BACKENDII-EFT — API REST (Spring Boot)

Backend desarrollado en **Java 17 + Spring Boot**, con enfoque en seguridad, documentación y buenas prácticas.

## Stack
- Spring Boot (Web, Actuator)
- Spring Security + JWT
- JPA (MySQL / H2)
- HATEOAS
- OpenAPI / Swagger UI (springdoc)
- Testing + cobertura (JUnit / JaCoCo)
- Validaciones (Bean Validation)

## Documentación incluida
- Implementación y demo de HATEOAS
- Guía de pruebas con Postman
- Soluciones a issues comunes (referencias cíclicas JSON, compilación)
